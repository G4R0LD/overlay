# 🎃 Halloween Overlay Collection

Добро пожаловать в коллекцию хэллоуинских оверлеев для OBS Studio! Здесь собраны атмосферные и интерактивные элементы, которые сделают ваш стрим по-настоящему жутким и стильным.

Все оверлеи работают на прозрачном фоне, поэтому их можно легко накладывать друг на друга в любом порядке.

---

## 🚀 Как это установить (Для стримеров)

Вам не нужно быть программистом, чтобы использовать эти эффекты. Всё уже работает!

1. Откройте OBS Studio.
2. Нажмите на плюсик в панели **«Источники»** и выберите **«Браузер»** (Browser).
3. В поле «URL» вставьте нужную ссылку (см. список ниже).
4. Установите **Ширину: 1920** и **Высоту: 1080**.
5. Поставьте галочку **«Выключить источник, когда он не виден»** (чтобы оверлей не кушал ресурсы вашего компьютера, когда вы скрываете сцену).

## 📂 Структура проекта
*   `skull3d.html` — 3D-череп (Three.js) + интеграция с Twitch API.
*   `pumpkins.html` — 3D-тыквы (Three.js) со сложным процедурным освещением.
*   `ghost.html` — 3D-призрак (Three.js) с кат-сценой скримера.
*   `candles/candles.html` — 2D-свечи (Canvas API).
*   `atmosphere/index.html` — 2D-атмосфера: мыши, кровь, паук (Canvas API).
*   `skull_model/`, `pumpkins_model/`, `ghost/` — папки с 3D-моделями (.gltf, .bin, textures).
*   `sounds/` — аудиофайлы (например, `skullfire.mp3`).

## 🛠️ Технический стек и архитектура

### 1. 3D-компоненты (`skull3d.html`, `pumpkins.html`, `ghost.html`)
*   **Технология:** Three.js (WebGL).
*   **Рендеринг:** Прозрачный фон (`alpha: true`), `ACESFilmicToneMapping`.
*   **Модели:** Загружаются через `GLTFLoader`.
*   **Интеграция с Twitch (Только для черепа):** 
    *   `skull3d.html` подключается напрямую к Twitch EventSub через WebSocket (`wss://eventsub.wss.twitch.tv/ws`).
    *   Для получения токенов используется Cloudflare Worker (эндпоинт `/token`, переменные окружения: `TWITCH_CLIENT_ID`, `TWITCH_ACCESS_TOKEN`, `BROADCASTER_ID` и KV-хранилище).
    *   Событие: `channel.channel_points_custom_reward_redemption.add` (активация награды вызывает тряску, свечение и звук).

### 2. 2D-компоненты (`candles.html`, `atmosphere/index.html`)
*   **Технология:** Чистый JavaScript + Canvas API (без сторонних библиотек).
*   **Свечи:** Рисуются послойно классом `CandleGroup`. Для свечения используется `globalCompositeOperation = 'lighter'`.
*   **Атмосфера:** Модульная система классов (`Bat`, `Blood`, `Ember`, `Spider`). Поддерживает URL-параметры для отключения эффектов (например, `?bats=0&blood=0`).

### 3. Скример призрака (`ghost.html`)
*   **Логика:** Управляется машиной состояний (State Machine): `IDLE` -> `FLY_IN` -> `SHAKE` -> `FLY_OUT`.
*   **Анимация:** Используется квадратичная кривая Безье для плавного полета и `Smoothstep` для ускорения/замедления.

## 💻 Локальная разработка
Из-за политики CORS браузеры блокируют загрузку 3D-моделей (`.gltf`/`.bin`), если просто открыть HTML-файл двойным кликом. 
Для тестирования используйте локальный сервер:
*   **VS Code:** Расширение "Live Server".
*   **Python:** `python -m http.server 8000` (затем открыть `http://localhost:8000`).
