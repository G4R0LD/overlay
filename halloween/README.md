# 🎃 Halloween Overlay Collection

Набор интерактивных и атмосферных оверлеев для OBS Studio, объединенных хэллоуинской тематикой. Все компоненты работают независимо друг от друга и используют прозрачный фон.

## 📦 Компоненты

В эту коллекцию входят:

1. **3D Череп (`skull3d.html`)** — Интерактивная 3D-модель черепа. Реагирует на награды Twitch (трясется, светится, проигрывает звук).
2. **3D Тыквы (`pumpkins.html`)** — Кинематографичная 3D-сцена с тремя тыквами и реалистичным мерцанием света от свечи (Three.js).
3. **2D Свечи (`candles/candles.html`)** — Группа свечей с анимированным пламенем и стекающим воском (Canvas API).
4. **Атмосфера (`atmosphere/index.html`)** — Фоновые эффекты: летучие мыши, стекающая кровь, светлячки, паук и вспышки молний. Поддерживает отключение эффектов через URL-параметры (например, `?bats=0&blood=0`).
5. **3D Призрак (`ghost.html`)** — Модель призрака со скример-анимацией для наград канала.

## 🛠️ Как добавить в OBS

1. Создайте источник **«Браузер»** (Browser Source).
2. Укажите **Ширину: 1920** и **Высоту: 1080** (для 3D-компонентов).
3. Вставьте прямую ссылку на нужный файл (см. ниже).
4. Убедитесь, что стоит галочка **«Выключить источник, когда он не виден»** (для экономии ресурсов).

## ⚙️ Технические детали

*   **Интеграция с Twitch (Череп):** Для работы интерактивности `skull3d.html` требует наличия настроенного Cloudflare Worker. Убедитесь, что в HTML-файле указан правильный URL вашего воркера, а в самом воркере прописаны токены Twitch.
*   **Обновление кэша:** Если вы внесли изменения в код, не забудьте в OBS нажать правой кнопкой мыши на источник и выбрать **«Обновить страницу»** (Refresh cache of current page).
*   **Зависимости:** Все 3D-модели используют библиотеку Three.js, которая подгружается автоматически. 2D-оверлеи работают на чистом JavaScript без сторонних библиотек.
