# 🎃 Halloween Stream Overlays (OBS + GitHub Pages)

Этот репозиторий содержит набор кастомных интерактивных и атмосферных оверлеев для стримов, созданных на HTML5, CSS, JavaScript и Three.js (WebGL). Все оверлеи разработаны для использования в OBS Studio через источник «Браузер» (Browser Source).

## 🌐 Деплой (GitHub Pages)
Проект хостится бесплатно через GitHub Pages. Автоматическая сборка и публикация сайта настроены через GitHub Actions (файл `.github/workflows/static.yml`). Любой коммит в ветку `main` автоматически обновляет сайт.

Сайт доступен по адресу: `https://g4r0ld.github.io/overlay/`

## 📂 Структура проекта

*   `skull3d.html` — **Интерактивный 3D-череп** (Three.js). Реагирует на награды Twitch.
*   `pumpkins.html` — **Статичные 3D-тыквы** (Three.js). С динамическим мерцающим светом.
*   `README.md` — Этот файл с общей документацией.
*   📁 `atmosphere/` — **2D Атмосфера** (`index.html`). Мыши, кровь, светлячки, молнии, паук.
*   📁 `candles/` — **2D Свечи** (`candles.html`). Группа оплывающих свечей с анимацией пламени.
*   📁 `skull_model/` — 3D-модель черепа (`.gltf`, `.bin`, текстуры).
*   📁 `pumpkins_model/` — 3D-модель тыкв (`.gltf`, `.bin`, текстуры).
*   📁 `sounds/` — Звуковые эффекты (например, `skullfire.mp3` для награды Twitch).
*   📁 `.github/` — Настройки CI/CD (GitHub Actions).

## 🏗 Архитектура компонентов

### 1. 💀 Череп (`skull3d.html`)
*   **Технология:** Three.js (WebGL). Прозрачный фон.
*   **Визуал:** 3D-модель черепа с зелеными светящимися глазами (PointLight + спрайты огня) и летящими искрами.
*   **Интерактив (Twitch):** Подключается по WebSocket к внешнему **Cloudflare Worker** (см. ниже). 
*   **Анимация награды:** При активации награды «Пощекотать череп» череп наклоняется, трясется, глаза вспыхивают ярче, искры ускоряются. Играет звук `sounds/skullfire.mp3` (через тег `<audio>`).

### 2. 🎃 Тыквы (`pumpkins.html`)
*   **Технология:** Three.js (WebGL). Прозрачный фон.
*   **Визуал:** Статичная 3D-модель трех тыкв с листьями.
*   **Освещение:** Имитация реалистичного света. Используется генератор шума (Value Noise) для плавного, непредсказуемого мерцания точечного источника света (`candleLight`), чтобы имитировать колыхание пламени свечи. Есть холодный контровой свет (луна) сзади и теплый спереди-слева.

### 3. 🌲 Атмосфера (`atmosphere/index.html`)
*   **Технология:** 2D Canvas API.
*   **Визуал:** Летучие мыши, тягучая кровь сверху, зеленые светлячки, спускающийся паук и случайные вспышки молний. Накладывается виньетка для затемнения краев.
*   **Настройка:** Поддерживает URL-параметры в OBS для отключения элементов (например, `?bats=0&blood=0&spider=0&lightning=0`).

### 4. 🕯️ Свечи (`candles/candles.html`)
*   **Технология:** 2D Canvas API.
*   **Визуал:** Плотная группа свечей с лужами воска. Пламя анимируется с помощью математических синусоид (`Math.sin`) и режима наложения `globalCompositeOperation = 'lighter'` для реалистичного свечения.

## ☁️ Внешний Бэкенд (Cloudflare Worker)

Для работы наград Twitch в `skull3d.html` используется **Cloudflare Worker** (находится на серверах Cloudflare, не в этом репозитории). Это сделано в целях безопасности, чтобы не хранить токены Twitch в открытом коде на GitHub.

**Как это работает:**
1.  Cloudflare Worker подключается к Twitch EventSub API по WebSocket.
2.  Worker отправляет POST-запрос в Twitch API для подписки на ивент `channel.channel_points_custom_reward_redemption.add`.
3.  При активации награды Worker пересылает JSON `{"type": "reward", "title": "Пощекотать череп"}` по WebSocket'у напрямую в OBS (в `skull3d.html`).
4.  **Автообновление:** В Worker'е настроен Cron-триггер и KV-хранилище (`TOKENS_KV`). Каждые 5 дней Worker сам запрашивает новые Access/Refresh токены у Twitch и сохраняет их. Вмешательство человека не требуется.

## 🛠 Как использовать в OBS

1.  Создайте источник **«Браузер» (Browser)**.
2.  Вставьте ссылку на нужный оверлей:
    *   Череп: `https://g4r0ld.github.io/overlay/skull3d.html`
    *   Тыквы: `https://g4r0ld.github.io/overlay/pumpkins.html`
    *   Атмосфера: `https://g4r0ld.github.io/overlay/atmosphere/`
    *   Свечи: `https://g4r0ld.github.io/overlay/candles/candles.html`
3.  Установите размер источника (обычно 1920x1080).
4.  Для черепа обязательно включите галочку **«Управлять аудио через OBS»** (Control audio via OBS), чтобы проигрывался звук награды.
5.  *Важно:* После любых изменений кода на GitHub всегда нажимайте ПКМ по источнику -> **«Обновить страницу» (Refresh)**, чтобы OBS сбросил кеш.
