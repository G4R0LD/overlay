# 🕯️ 2D Candles Overlay (OBS)

Этот проект представляет собой 2D-оверлей с анимацией группы свечей, написанный на чистом HTML5 Canvas и JavaScript. 
Оверлей отображает несколько плотно стоящих свечей с реалистично стекающим воском и анимированным пламенем, имитирующим настоящий огонь. Оверлей не требует подключения к API и работает автономно.

## 🏗 Архитектура и принцип работы

1. **OBS Browser Source:** Открывает `candles.html` с GitHub Pages.
2. **2D Canvas (JavaScript):** Рисует свечи, используя математические кривые и градиенты.
3. **Анимация:** Движение пламени достигается за счет изменения высоты и формы огня в цикле `requestAnimationFrame` с использованием синусоид (`Math.sin`).

---

## ⚙️ Технические детали (Как устроен код)

Весь код построен вокруг класса `CandleGroup`, который отрисовывает всю композицию слой за слоем:

1. **Общее свечение (Glow):** 
   Создается радиальный градиент (`createRadialGradient`) с теплым оранжевым оттенком, который накладывается на фон, создавая эффект света, исходящего от группы свечей.
2. **Лужа воска (Puddle):** 
   Рисуется с помощью сложных кривых Безье (`bezierCurveTo`), чтобы края лужи были неровными и органичными. Сверху добавляются белые блики и мелкие капли воска.
3. **Тело свечи (Body):** 
   Используется линейный градиент (`createLinearGradient`) слева направо, чтобы создать иллюзию объема (тень слева, свет по центру, тень справа). 
   Стекающий воск рисуется отдельными фигурами поверх тела свечи.
4. **Пламя и фитиль (Flame):**
   * Огонь имеет многослойную структуру: внешнее оранжевое пламя, внутреннее желтое и белое ядро.
   * Свойство `globalCompositeOperation = 'lighter'` заставляет цвета пламени смешиваться и светиться, создавая реалистичный эффект света.
   * Высота и форма пламени (`flameH`) постоянно меняются с помощью `Math.sin(timeOffset)` и `Math.cos(timeOffset * 3)`, из-за чего свечи мерцают вразнобой.

## 🛠 Как вносить изменения

**Изменить количество или расположение свечей:**
Найти в коде функцию `draw()` внутри `CandleGroup`. Там есть вызовы `this.drawCandle(x, y, width, height, timeOffset)`. Каждая такая строчка — одна свеча. Меняя координаты и размеры, можно построить другую композицию.

**Изменить скорость мерцания:**
В функции `drawCandle` найти параметр `flameH = 30 + Math.sin(timeOffset) * 5 ...`. Если увеличить число `5`, пламя начнет "плясать" сильнее. Чтобы ускорить ритм, нужно менять множители внутри `Math.sin`.

**Изменить общее свечение:**
В функции `draw()` найти `const groupGlow = ctx.createRadialGradient(...)`. Последний параметр (350) отвечает за радиус свечения. Цвета можно менять в `addColorStop`.

## ⚠️ Важные нюансы (Troubleshooting)
1. **Кеш OBS:** После изменений в коде не забудь нажать ПКМ по источнику -> **"Обновить страницу"**.
2. **Масштаб:** Свечи позиционируются от центра экрана. Лучше всего использовать этот оверлей с размером источника в OBS 1920x1080 или 1080x1080 (квадрат), чтобы ничего не обрезалось.
