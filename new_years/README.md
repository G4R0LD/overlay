# 🎄 Новогодние оверлеи (New Year Overlays)

Эта папка содержит новогодние оверлеи для OBS Studio. Все они подключаются как источник **«Браузер» (Browser Source)**, имеют прозрачный фон и работают независимо друг от друга.

## 📦 Состав папки

| Файл | Название | Тип | Назначение |
|------|----------|-----|------------|
| `колокол.html` | **3D Колокольчик** | Интерактивная награда Twitch | Звенит при активации награды |
| `пряня.html` | **Анимированный Пряня (Gingy)** | Интерактивная награда Twitch | Встаёт в позу, машет рукой, появляется надпись «Привет!» |
| `лакричная рамка.html` | **3D Рамка «Карамель с сахаром»** | Декоративный элемент | Просто 3D-рамка для украшения сцены |

## 🧩 Описание оверлеев

### 🔔 3D Колокольчик (`колокол.html`)
Интерактивная награда канала Twitch. При активации награды колокольчик **звенит**. Всё.

**Подключение в OBS:**
1. Создайте источник «Браузер».
2. Укажите ссылку: `https://g4r0ld.github.io/overlay/new_years/колокол.html`
3. Задайте размер источника (обычно 1920×1080).
4. При необходимости включите «Управлять аудио через OBS», если используется звук.

### 🍪 Анимированный Пряня (Gingy) (`пряня.html`)
Интерактивная награда канала Twitch, но в 2D. При активации награды пряня **проигрывает анимацию: встаёт в позу и машет рукой**, в этот момент появляется надпись **«Привет!»**. На этом его функционал заканчивается.

**Подключение в OBS:**
1. Создайте источник «Браузер».
2. Укажите ссылку: `https://g4r0ld.github.io/overlay/new_years/пряня.html`
3. Настройте размер и положение источника.

### 🍬 3D Рамка «Карамель с сахаром» (`лакричная рамка.html`)
Декоративная 3D-рамка. По сути, это просто рамка — она могла бы быть и обычной картинкой. Используется для украшения сцены (например, для веб-камеры или игрового окна).

**Подключение в OBS:**
1. Создайте источник «Браузер».
2. Укажите ссылку: `https://g4r0ld.github.io/overlay/new_years/лакричная%20рамка.html`
3. Разместите рамку поверх нужного элемента сцены.

## ⚙️ Общие рекомендации

* Все оверлеи имеют прозрачный фон и могут наслаиваться друг на друга.
* После изменений в коде обновляйте источник в OBS (ПКМ → «Обновить страницу»), чтобы сбросить кеш.
* Новогодние оверлеи можно комбинировать с основными оверлеями проекта.
