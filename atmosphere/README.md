# 🌲 Halloween Atmosphere Overlay (OBS)

Этот проект представляет собой 2D-оверлей с атмосферными эффектами для Хэллоуина, написанный на чистом HTML5 Canvas и JavaScript.
Он включает в себя: летающих мышей, стекающую кровь, зеленых светлячков (искры), спускающегося паука и случайные вспышки молний на заднем плане.

## 🏗 Архитектура и принцип работы

1. **OBS Browser Source:** Открывает `index.html` с GitHub Pages.
2. **2D Canvas:** Отрисовка всех эффектов происходит через математические формулы и циклы.
3. **Модульность (URL-параметры):** Оверлей поддерживает включение/отключение отдельных эффектов через URL-адрес (см. ниже).

---

## ⚙️ Технические детали (Как устроен код)

Код разбит на классы, каждый из которых отвечает за свой элемент:

1. **Класс `Bat` (Летучие мыши):** 
   Мыши летят горизонтально с краев экрана. Анимация взмаха крыльев достигается за счет изменения координаты Y крыла по синусоиде (`Math.sin(this.t * 2)`).
2. **Класс `Blood` (Кровь):** 
   Тягучие капли стекают сверху вниз. Имеют градиент от темно-бордового к красному. Скорость и ширина капли задаются случайным образом при спавне.
3. **Класс `Ember` (Светлячки/Искры):** 
   Зеленые точки, которые медленно поднимаются снизу вверх. Имеют радиальный градиент (свечение) и хаотично меняют свою прозрачность.
4. **Класс `Spider` (Паук):** 
   Спускается по паутинке сверху вниз, висит на месте (фаза 1), а затем уползает обратно наверх.
5. **Молния (`triggerLightning`):**
   Раз в случайный промежуток времени (от 1.2 до 4 секунд) генерируется ломаная линия, имитирующая молнию. Экран на долю секунды озаряется холодным сине-белым светом.

## 🛠 URL-параметры (Настройка в OBS)

Вы можете отключать ненужные эффекты, просто добавляя параметры к ссылке в OBS (через `&`). Например: `.../atmosphere/index.html?bats=0&blood=0`

*   `?bats=0` — отключить летучих мышей.
*   `?blood=0` — отключить стекающую кровь.
*   `?lightning=0` — отключить молнии.
*   `?spider=0` — отключить паука.
*   `?scene=1` — добавить темный фон (для просмотра в браузере, в OBS не включать!).

## 🛠 Как вносить изменения в код

**Количество объектов:**
Найти блок `// ---------- ИНИЦИАЛИЗАЦИЯ ----------` внизу кода. Там задается количество мышей (`Array.from({length:5})`), капель крови (`length:8`) и светлячков (`length:30`). Можно менять эти цифры для изменения плотности эффектов.

**Цвет светлячков:**
В классе `Ember` в методе `draw()` найти `rgba(100, 255, 100, ...)`. Если изменить эти цифры (например, на `255, 100, 100`), светлячки станут красными.

**Радиус и яркость виньетки (затемнения по краям):**
В функции `loop()` найти `const vg = ctx.createRadialGradient(...)`. Там есть строка `rgba(5, 10, 20, 0.6)` — последнее число (0.6) отвечает за силу затемнения краев.

## ⚠️ Важные нюансы (Troubleshooting)
1. **Кеш OBS:** После любых изменений в коде обязательно обновляй страницу в OBS.
2. **Виньетка:** В самом низу кода в функции `loop()` накладывается темное затемнение по краям экрана. Оно нужно, чтобы атмосферные эффекты лучше сливались с игрой. Если оно мешает, можно уменьшить значение `0.6` до `0.2`.
